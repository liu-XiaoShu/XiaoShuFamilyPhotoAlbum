      小树时光相册 v3.0.9
      
              
      作者 · xiaoshu · 更新时间 2026-10-25
      
            
      
          
      

          
      
            
      简介
      
            
      
              局域网轻量相册：把照片/视频按时间归档到本机目录，元数据写进文件，支持时光浏览、地图足迹、入库整理、回收站与扫码分享。
            
      
          
      

          
      
            
      主要功能
      
            
        
              
      • 相册浏览：时光 / 经典 / 地图；搜索；实况预览；下载原图
        • 
              
      • 入库：自动解析、上传队列、内容去重（忽略元数据）、待入库移除/清空
        • 
              
      • 无拍摄时间时可用文件名中的日期时间；HEIC / 实况原件入库
        • 
              
      • 地图：国内纠偏、港澳台与境外按 WGS-84；地点库可含世界城市
        • 
              
      • 单图编辑：旋转裁剪、视频剪辑与封面
        • 
              
      • 超级用户与分享二维码；存储占用与重复项处理
        • 
              
      • 回收站软删除；媒资 SQLite 索引加速浏览
        • 
              
      • 手机窄屏浏览布局；手机端降低缩略图 / 预览负载
        • 
            
      
            
      文件命名：年/月/YYYY-MM-DD-HHMMSS-简述-md5.扩展名
      
          
      

          
      
            
      本版更新
      
            
        
              
      • 手机幻灯片画面铺满并居中，看图用清晰预览
        • 
              
      • 存储页分成「占用」和「查重」；访问数据先出汇总
        • 
              
      • 入库解析按数据库里的内容指纹标出相册已有的相同文件
        • 
              
      • 还没有超级用户时必须先注册，相册不再对局域网开放全部权限
        • 
              
      • 苹果 Safari：幻灯片里打开编辑，窗口可以完整显示
        • 
              
      • Mac 入库「从相册选择」可以打开「照片」图库
        • 
              
      • 入库提示相册已有相同内容时，可点开展开所在位置
        • 
              
      • 手机看图画面居中，顶部的编辑、播放、设置可以点到
        •
