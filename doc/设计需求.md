## 1. 背景与目标

### 1.1 背景

相册分散在多目录，缺少统一时间组织与可随文件迁移的说明信息。需要一套**本机/局域网**工具：把照片与视频整理进约定目录，在页面上浏览、修订，并可安全分享给家人。

### 1.2 产品目标

| 目标 | 说明 |
|------|------|
| 统一归档 | 按「年 / 月 / 详细时间-简述-内容指纹」结构入库 |
| 元数据伴随 | 时间、简述、描述、地点写入文件元数据（及侧车） |
| 可纠错 | 入库前与入库后均可修正 |
| 流畅浏览 | 时光 / 经典 / 地图；大纲 + 按月分页；地图服务端聚簇，目标十万级可流畅浏览 |
| 可控权限 | 超级用户；分享二维码按范围授权 |
| 轻量局域网 | 单机服务，不做公网社交 |

### 1.3 非目标

- 公网多租户、云同步、评论互动  
- 专业 RAW 暗房 / AI 自动标签  
- 依赖独立商业图库账号（默认高德公开瓦片免密钥；天地图企业认证已弃用）

## 3. 总体架构

```
浏览器（局域网）
  登录 / 浏览（时光·经典·地图）/ 管理 / 设置 / 访问数据 / 关于
        │ HTTPS
FastAPI（run.py / Docker）
  鉴权 · 入库 · 元数据 · 缩略图 · 地图代理 · 访客统计 · 分享
        │
album/  年/月/规范文件
data/   auth · visitors · thumbs · map_pack · geo · brand
inbox/  待入库
```

**原则：** 文件系统 = 媒资真相；SQLite 索引可重建；用户确认后才落盘。

## 5. 功能清单（已实现）

### 5.1 登录与权限

- 未登录 → `/login`；匿名媒资拒绝（已建超管后）  
- 分享：`/?share=token` → Cookie；可见 = 授权范围 ∪ 该访客自己入库  
- 重置密码：`python3 run.py --reset-admin-password`  
- 登录/刷新默认进入**时光**浏览  

### 5.2 浏览与管理

- 时光 / 经典 / 地图（高德或离线）  
- **规模**：`/api/timeline/outline` + `/api/timeline/month` 按需加载；经典模式滚动分页；地图 `/api/map/clusters` 服务端聚簇  
- 入库拖放、**移除选中 / 清空待入库**、回收站、设置、**访问数据**（含入库占比）、关于  

### 5.3 编辑

- 图片旋转裁剪；视频剪辑与封面；旁白录音  

### 5.4 地图

- `map_provider`: `auto` | `amap` | `offline`（改偏好立即失效 pack 状态缓存）  
- 高德：服务端拉取 + `data/map_pack/xyz_amap` 缓存；坐标 WGS84→GCJ-02  
- 离线：`xyz` / MBTiles；设置页文案与真实 `effective_provider` 一致  

### 5.5 运维脚本

- `scripts/pi/deploy.sh` / `start.sh` / `stop.sh` / `restart.sh` / `debug.sh`  
- 统一入口：`scripts/pi/xiaoshu-ctl.sh`
