# 小树时光相册 · 使用说明

> 适用版本：**v3.0.8**（更新时间 2026-10-11）  
> 部署见 [部署使用说明.md](./部署使用说明.md)，安全见 [安全说明.md](./安全说明.md)，版本对照见 [版本说明.md](./版本说明.md)。

---

## 1. 首次使用

1. 打开 `https://<主机IP>:8765/login`（自签证书点「继续访问」）。  
2. **立刻创建超级用户**（用户名不会预填，请自行输入；密码需足够强）。  
3. 登录后进入「相册浏览 / 相册管理」。

还没有超管时，只能打开登录页创建账号，相册照片不可读写。同网段仍可能抢先注册，务必先建号。

## 2. 入库

路径：**相册管理 → 入库**

1. 将照片/视频**拖入**虚线框，或点「从相册选择」（手机端隐藏「选文件夹」）。网页不能指定打开 Mac「照片」图库：Safari 请在文件框侧栏点「照片」，Chrome 会从「图片」文件夹开始。  
2. 文件进入**上传队列**：可暂停 / 继续 / 重试失败 / 清空已完成；手机端默认逐个上传并显示进度。  
3. 列表加载时会**自动解析 EXIF/侧车**（时间、简述、地点等），可直接改字段；一般不必再点「重新解析」。无拍摄时间时，会尝试从**文件名**里的日期时间填写。  
4. 勾选后点 **入库选中项** 写入 `album/`。  
5. 不要入库的：勾选后点「移除选中」，或「清空待入库」（只从导入区删除文件，**不会**进相册、也**不会**进回收站）。  

### 去重与实况

- **内容相同**的文件入库时会自动跳过，解析列表会标出「相册已有相同内容」。指纹按画面/视频载荷计算，**改 EXIF、旋转标记等元数据通常仍视为同一张**；重新压缩或改过尺寸不算同一份。  
- 存储页「检查重复项」用同一套指纹；若以前用整文件 MD5 扫过，升级后可再扫一次。  
- **苹果实况**：请同时选 HEIC 与同名 MOV；入库 HEIC 时会带走伴生视频（`.live.mov`）。伴生 MOV 默认不单独勾选入库。  

命名规范：

```text
album/年/月/YYYY-MM-DD-HHMMSS-简述-md5前8位.扩展名
```

支持 JPEG / HEIC / PNG / 常见视频（MOV/MP4 等）。原件按字节拷贝入库，不转码压画质。浏览器无法直接播放的视频，看图时可能走服务端转码，不影响相册里的原文件。

> 一次导入很多大视频时，受 Wi‑Fi 与树莓派磁盘限制，仍可能较慢；可分批导入。相册与待入库请放在**同一块磁盘**（例如同一 USB 盘），避免入库时跨盘拷贝。

## 3. 浏览、搜索与下载

路径：**相册浏览**（登录后默认**时光**）

| 模式 | 说明 |
|------|------|
| 时光 | 按年/月折叠时间线（首屏最轻） |
| 经典 | 按日网格浏览 |
| 地图 | 按地点聚点；点击堆叠展开该地点图集 |

**搜索：** 默认收起。点顶栏「搜索」展开输入框，可按标题、地点、描述、文件名查找；「收起 / 清除结果」可关闭。

**看图：** 单击缩略图进入沉浸灯箱。

| 按钮 | 作用 |
|------|------|
| 下载 | 下载当前原文件（`/api/download`） |
| 实况 | 有伴生视频时播放实况（也可长按预览图） |
| 编辑 | 改元数据 / 旋转裁剪 / 视频剪辑封面 / 旁白 |
| 播放 | 自动轮播（可调模式与时长） |

编辑页同样提供「下载原文件」。

## 4. 地图底图

路径：**管理 → 设置 → 地图底图**

| 模式 | 说明 |
|------|------|
| 自动 / 高德在线 | 默认；国内快、免注册；服务端代理并缓存 |
| 离线包 | 断网或强制本地瓦片；可点「更新地图包」联网补全 |

照片 GPS：中国大陆在高德模式下会做坐标校正；**香港、澳门、台湾及境外**按 WGS-84 落点，避免纠偏到邻近城市。

地点写的是「曼谷」「清迈」等而地图没有点时，需要地点库里有对应城市。国内库用 `scripts/seed_places.py` 生成；海外增补：

```bash
python3 scripts/seed_world_places.py
# 指定库路径：
PLACES_DB=/path/to/data/geo/places.sqlite python3 scripts/seed_world_places.py
```

## 5. 分享

路径：**管理 → 设置 → 分享相册**（需超管）

1. 选择按**年份**或**指定媒资**，勾选范围（不可为空）。  
2. 可选「允许入库」：访客可上传；其**自己入库**的内容本人仍可见。  
3. 生成二维码 / 复制链接：`https://主机/?share=令牌`。  
4. 家人扫码免登进入，可见 = **授权范围 ∪ 自己上传**。  

建议：只读分享不要勾「允许编辑 / 入库」；用完可停用或删除链接。

## 6. 存储与重复项（超管）

路径：**相册管理 → 存储**（与「设置」同级，仅超级用户可见）

- 页面分成两组：**存储占用**（磁盘水位、相册原片、回收站、待入库、缩略图、离线地图包）和 **查重**。相册原片体积来自索引。  
- **重新统计**只重算回收站、待入库、缩略图、地图包等目录体积，不改照片、不清指纹。  
- **检查重复项**：补算内容指纹并列出重复组。  
- 每组勾选要**保留**的一份 →「其余移入回收站」。  
- **一键处理（留最早 / 留最新）**：批量处理所有重复组。  

回收站物理路径：`album/.trash/`（见部署文档备份说明）。

## 7. 访问数据

路径：**管理 → 访问数据**（仅超管）

- 访问曲线、当前/历史访客、高频图片  
- **入库占比**与**入库明细**  
- 黑名单（IP / MAC）  

缩略图、预览图和瓦片请求不计入访问统计。打开页面时先出摘要，其余统计随后补齐。

## 8. 其他设置

| 项 | 说明 |
|----|------|
| 相册名称与图标 | 页眉品牌 |
| 主题 | 科技清新 / 科技赛博（存本机浏览器） |
| 相册根目录 / 缩略图目录 | 可迁到外接盘并迁移已有数据 |
| 媒资索引 | 重建 SQLite 目录以加速浏览。不删除、不改写照片文件，并保留已有内容指纹。开始前会确认 |

忘记超管密码（在服务器上）：

```bash
python3 run.py --reset-admin-password
# 或 Docker：见部署文档
```

## 9. 回收站

路径：**管理 → 回收站**

- 软删除可恢复；「彻底删除」仅超管。  
- 选择逻辑与相册月度选择一致（圆勾、全选等）。  
- 分享访客若具备编辑权限，也只能看到/恢复**自己可见范围**内的条目。

## 10. 常用接口（开发/排障）

| 接口 | 说明 |
|------|------|
| `GET /api/health` | 健康与版本（含 `released_at`） |
| `GET /api/download?path=` | 下载原文件（需登录/分享可见） |
| `GET /api/search?q=` | 搜索 |
| `GET /api/storage` | 存储统计（超管） |
| `POST /api/import/discard` | 移除待入库（`paths` 或 `clear_all`） |
| `POST /api/dedup/scan` | 补算指纹（超管） |
| `POST /api/dedup/resolve` | 处理一组重复（超管） |
