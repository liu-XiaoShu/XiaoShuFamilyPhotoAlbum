# 小树时光相册 · 使用说明

面向日常使用。部署见 [部署使用说明.md](./部署使用说明.md)，安全见 [安全说明.md](./安全说明.md)。

---

## 1. 首次使用

1. 打开 `https://<主机IP>:8765/login`（自签证书点「继续访问」）。  
2. **立刻创建超级用户**（用户名 + 强密码）。  
3. 登录后进入「相册浏览 / 相册管理」。

未创建超管前，服务处于**开放模式**：同网段任意设备可读写相册。务必先建号。

---

## 2. 入库

路径：**相册管理 → 入库**

1. 将照片/视频**拖入**下方虚线框，或点「从相册选择 / 选择文件夹」。  
2. 列表出现后：可「解析源数据」预填时间与地点，「批量编辑」修正。  
3. **入库选中项**：勾选后写入 `album/`。  
4. **不要入库**的：勾选后点「移除选中」；或「清空待入库」一次清掉。  

入库后文件进入 `album/年/月/`，命名为：

```text
YYYY-MM-DD-HHMMSS-简述-md5前8位.扩展名
```

支持 JPEG / HEIC / PNG / 常见视频（MOV/MP4 等；不含 `.ts`，以免与 TypeScript 源码冲突）。原件按字节拷贝，不转码压画质。

> 一次拖入数百文件时，树莓派可能因写盘与预览缩略图变慢；可分批导入，或将相册目录放到 USB 硬盘。

---

## 3. 浏览

路径：**相册浏览**（登录后默认进入**时光**）

| 模式 | 说明 |
|------|------|
| 时光 | 按年/月折叠时间线（首屏最轻） |
| 经典 | 按日网格浏览 |
| 地图 | 按地点聚点；点击堆叠展开该地点图集 |

单击照片进入沉浸看图；可编辑（旋转裁剪、视频封面、旁白等，需编辑权限）。

---

## 4. 地图底图

路径：**管理 → 设置 → 地图底图**

| 模式 | 说明 |
|------|------|
| 自动 / 高德在线 | 默认；国内快、免注册；服务端代理并缓存 |
| 离线包 | 断网或强制本地瓦片；可点「更新地图包」联网补全 |

照片 GPS 在高德模式下会自动做坐标校正，避免点位偏移。

---

## 5. 分享

路径：**管理 → 设置 → 分享相册**（需超管）

1. 选择按**年份**或**指定媒资**，勾选范围（不可为空）。  
2. 可选「允许入库」：访客可上传；其**自己入库**的内容即使不在原授权年份内，本人仍可见。  
3. 生成二维码 / 复制链接：`https://主机/?share=令牌`。  
4. 家人扫码免登进入，可见 = **授权范围 ∪ 自己上传**。  

建议：只读分享不要勾「允许编辑 / 入库」；用完可停用或删除链接。

---

## 6. 访问数据

路径：**管理 → 访问数据**（仅超管）

- 访问曲线、当前/历史访客、高频图片  
- **入库占比**（按用户饼图）与**入库明细**（谁、何时、哪张）  
- 黑名单（IP / MAC）  

缩略图 / 瓦片请求不计入访问统计，以免拖慢设备。

---

## 7. 其他设置

| 项 | 说明 |
|----|------|
| 相册名称与图标 | 页眉品牌 |
| 主题 | 科技清新 / 科技赛博（存本机浏览器） |
| 相册根目录 / 缩略图目录 | 可迁到外接盘并迁移已有数据 |
| 媒资索引 | 重建 SQLite 索引以加速浏览 |

忘记超管密码（在服务器上）：

```bash
python3 run.py --reset-admin-password
# 或 Docker：见部署文档
```

---

## 8. 回收站

路径：**管理 → 回收站**

软删除可恢复；「彻底删除」仅超管。分享访客不应依赖回收站权限（详见安全说明）。
