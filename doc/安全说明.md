# 小树时光相册 · 安全说明

> 评估日期：2026-10-11 · 适用版本 **v3.0.8**  
> 场景：家庭局域网相册（Docker host / 直连 uvicorn）

---

## 1. 权限模型（简）

| 身份 | 媒资访问 | 管理能力 |
|------|----------|----------|
| **未创建超管** | **不可**访问照片/缩略图/原文件/下载 | 只能打开登录页创建超级用户 |
| **已有超管、未登录** | **不可**访问照片/缩略图/原文件/下载 | 仅健康检查、登录、部分公开配置 |
| **超级用户** | 全部 | 设置、分享、访问数据、存储、彻底删除、去重处理 |
| **分享会话** | 仅创建时勾选的年份或媒资 ∪ 自己上传 | 按分享勾选的编辑/上传；回收站仅可见范围内条目 |

结论（针对「没登录也能看图」）：

- **超管创建之后**：未登录不能通过 API 拉取相册媒资；前端也会跳转登录页。  
- **超管创建之前**：相册本身不可读写，但同网段任何人都能打开登录页抢先注册 → **务必首启立刻建号**。

## 2. 风险摘要

### 严重

| 风险 | 说明 | 建议 |
|------|------|------|
| 首启抢注 | 无超管时同网段任何人都能抢先完成注册 | 部署后立刻在本机建号；建号前不要把端口暴露到不可信网络 |

### 中等

| 风险 | 说明 | 建议 |
|------|------|------|
| 分享链接在 URL | `?share=` 易进浏览器历史、Referer、访问日志 | 用完删除/停用；勿转发到不可信渠道 |
| Docker `network_mode: host` | 整网段可达 8765，无应用层 IP 白名单 | 路由器隔离访客 Wi‑Fi；仅信任设备接入 |
| 登录/分享进入无限速 | 可暴力尝试密码或分享令牌 | 强密码；轮换分享；必要时网络层限速 |
| 地图/地点部分接口免登 | 瓦片与地点解析可被同网段调用 | 家庭网一般可接受；勿端口映射到公网 |
| X-Forwarded-For | 直连时伪造头可能影响 IP 黑名单 | 无反代时黑名单以直连 IP 为准 |
| 自签 HTTPS + Safari Cookie | 证书不受信时可能丢 `Secure` Cookie | 统一用 HTTPS；信任证书；避免无痕乱拦 Cookie |
| 下载接口 | `/api/download` 可带走原文件 | 仅对已授权主体开放；分享勿给不可信对象 |

### 低

- 自签证书用局域网 IP 访问会有警告  
- `/api/health` 暴露版本号与更新日期（非敏感）  
- 登录页已取消用户名预填，降低轻微信息暴露  

### v2.0.0 已收紧

- 回收站列表/恢复对分享访客按 `media_visible` 过滤  
- 新写入文件尽量 `chmod`/`chown`（`HOST_UID`），降低宿主机侧权限混乱  
- 下载、预览、可播转码接口均走登录/分享可见性校验  

---

## 3. 做得较好的部分

- 已建超管后，匿名默认拒绝媒资路径  
- 相册路径有根目录约束，防止 `../` 穿越  
- 会话 Cookie：`HttpOnly` + `SameSite=Lax`；HTTPS 下带 `Secure`  
- 分享创建禁止空范围；配置/访问数据/存储/去重写入需超管  
- 下载与原文件读取均走权限校验  

---

## 4. 部署加固清单

1. **安装后立即创建超级用户**，确认未登录无法打开相册。  
2. **不要**把 8765 端口映射到公网；仅局域网。  
3. 使用默认 **HTTPS**；家人设备信任一次自签证书；勿混用 HTTP/HTTPS。  
4. 分享链接最小权限、用完即停用；重要相册避免勾选「允许编辑」。  
5. 定期备份 `album/`（含需要的 `.trash`）与 `data/auth.sqlite`，勿把含真实照片的目录推到公开 Git。  
6. 路由器开启访客网络隔离。  
7. compose 配置 `HOST_UID`/`HOST_GID`，并对 `album`/`inbox`/`data` 做一次宿主机属主校正。  
8. **公开 GitHub**：只提交源码与示例配置。勿提交 `config.json`、证书、`album/`、`inbox/`、`data/`。现有 Git 历史里可能含本机路径，公开仓库请用**无历史的新仓库**推送当前工作区，不要把旧 `main` 整段历史推上去。

## 5. 「局域网入侵」现实评估

在**已建超管、仅家庭可信设备、未做公网暴露**的前提下：

- 陌生人未登录**不能**直接刷接口看/下载原图（需猜分享令牌或攻破账号）。  
- 同网段恶意设备仍可：探测服务、耗地图带宽、撞库登录、在首启窗口抢先注册超管。  
- 最大威胁通常是：**家人设备失窃后的有效会话/分享链接**，以及 **首启未建号**。

本项目面向「可信任的家庭局域网」，不是面向公网的多租户相册。若需求升级到公网，需要额外的反向代理、强制 HTTPS、登录限速、关闭 host 网络等，不在当前 v3.0.8 范围。
