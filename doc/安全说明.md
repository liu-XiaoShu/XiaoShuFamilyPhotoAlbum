# 小树时光相册 · 安全说明

> 评估日期：2026-09-23 · 适用版本 v1.0  
> 场景：家庭局域网相册（Docker host / 直连 uvicorn）

---

## 1. 权限模型（简）

| 身份 | 媒资访问 | 管理能力 |
|------|----------|----------|
| **未创建超管（开放模式）** | 全部可读可写 | 等同超管（危险窗口） |
| **已有超管、未登录** | **不可**访问照片/缩略图/原文件 | 仅健康检查、登录、部分公开配置 |
| **超级用户** | 全部 | 设置、分享、访问数据、彻底删除 |
| **分享会话** | 仅创建时勾选的年份或媒资 | 按分享勾选的编辑/上传能力 |

结论（针对「没登录也能看图」）：

- **超管创建之后**：未登录不能通过 API 拉取相册媒资；前端也会跳转登录页。  
- **超管创建之前**：同网段任何人都能看图、改图、抢注超管账号 → **务必首启立刻建号**。

---

## 2. 风险摘要

### 严重

| 风险 | 说明 | 建议 |
|------|------|------|
| 首启开放模式 | 无 `admin` 时 `open_mode=True`，局域网任意设备全权限 | 部署后第一件事创建超管；或临时只在本机访问完成初始化 |

### 中等

| 风险 | 说明 | 建议 |
|------|------|------|
| 分享 + 回收站 | 部分分享场景下回收站列表/恢复校验不够严 | 分享勿开「允许编辑」；敏感时期停用分享 |
| 分享链接在 URL | `?share=` 易进浏览器历史、Referer、访问日志 | 用完删除/停用；勿转发到不可信渠道 |
| Docker `network_mode: host` | 整网段可达 8765，无应用层 IP 白名单 | 路由器隔离访客 Wi‑Fi；仅信任设备接入 |
| 登录/分享进入无限速 | 可暴力尝试密码或分享令牌 | 强密码；轮换分享；必要时网络层限速 |
| 地图/地点部分接口免登 | 瓦片与地点解析可被同网段调用 | 家庭网一般可接受；勿端口映射到公网 |
| X-Forwarded-For | 直连时伪造头可能影响 IP 黑名单 | 无反代时黑名单以直连 IP 为准（后续版本将收紧） |
| 照片标题 XSS | 恶意简述可能注入页面 | 已对列表标题做转义；仍勿给不可信用户编辑权 |

### 低

- 自签证书 SAN 多为 localhost，用局域网 IP 访问会有警告  
- `/api/health`、`/api/config` 对匿名暴露版本/年份等非敏感信息  
- 允许上传 SVG 品牌图标（以 `<img>` 加载，风险较低）

---

## 3. 做得较好的部分

- 已建超管后，匿名默认 `media_paths=["__none__"]`，媒资路径校验拒绝越权  
- 相册路径有根目录约束，防止 `../` 穿越到系统目录  
- 会话 Cookie：`HttpOnly` + `SameSite=Lax`；HTTPS 下带 `Secure`  
- 分享创建禁止空范围；访问数据/配置写入类接口需超管  

---

## 4. 部署加固清单

1. **安装后立即创建超级用户**，确认未登录无法打开相册。  
2. **不要**把 8765 端口映射到公网；仅局域网。  
3. 使用默认 **HTTPS**；家人设备信任一次自签证书。  
4. 分享链接最小权限、用完即停用；重要相册避免勾选「允许编辑」。  
5. 定期备份 `album/` 与 `data/auth.sqlite`，勿把含真实照片的目录推到公开 Git。  
6. 路由器开启访客网络隔离（访客 Wi‑Fi 不能访问 NAS/相册主机）。  

---

## 5. 「局域网入侵」现实评估

在**已建超管、仅家庭可信设备、未做公网暴露**的前提下：

- 陌生人未登录**不能**直接刷接口看原图（需猜分享令牌或攻破账号）。  
- 同网段恶意设备仍可：探测服务、耗地图带宽、撞库登录、在首启窗口抢超管。  
- 最大威胁通常是：**家人设备失窃后的有效会话/分享链接**，以及 **首启未建号**。

本项目面向「可信任的家庭局域网」，不是面向公网的多租户相册。若需求升级到公网，需要额外的反向代理、强制 HTTPS、登录限速、关闭 host 网络等，不在当前 v1.0 范围。
