# 小树时光相册 · Docker 部署与使用说明

本文说明在 Linux 服务器（含树莓派 Ubuntu）上用 Docker 部署、启动、查状态，以及重置超级用户密码的方法。

本地开发仍可用：

```bash
python3 run.py          # 默认 HTTPS
python3 run.py --http   # 明文 HTTP（仅调试）
```


---

## 1. 环境要求

- Docker + docker-compose（Ubuntu 可用：`sudo apt install docker.io docker-compose`）
- 当前用户在 `docker` 组，或命令前加 `sudo`
- 开放端口 **8765**（局域网访问）

本仓库已配置国内加速：

| 用途 | 源 |
|------|-----|
| 基础镜像 | DaoCloud（`docker.m.daocloud.io`） |
| 容器内 apt | 清华 Debian |
| pip | 清华 PyPI |

建议在宿主机配置 Docker 镜像加速（`/etc/docker/daemon.json`），例如：

```json
{
  "registry-mirrors": [
    "https://docker.m.daocloud.io",
    "https://docker.1ms.run",
    "https://mirror.ccs.tencentyun.com"
  ]
}
```

修改后执行：`sudo systemctl restart docker`

## 2. 部署流程

### 2.1 准备目录

将项目放到服务器，例如：

```bash
# 示例路径（可按需修改）
mkdir -p ~/apps/xiaoshu-album
# 把本仓库文件同步到该目录（含 Dockerfile、docker-compose.yml、app/ 等）
cd ~/apps/xiaoshu-album
```

确保存在：

```bash
cp -n config.example.json config.json   # 若还没有 config.json
mkdir -p album inbox data/thumbs data/brand data/map_pack data/geo
```

`config.json` 中常用项：

```json
{
  "album_root": "album",
  "import_root": "inbox",
  "host": "0.0.0.0",
  "port": 8765,
  "album_title": "小树时光相册",
  "map_provider": "auto"
}
```

地图底图：默认高德在线（免注册）；`map_provider` 可为 `auto` / `amap` / `offline`。断网时用离线包。

以后外接硬盘可把 `album_root` 改成绝对路径（如 `/mnt/hdd/album`），并在 `docker-compose.yml` 里增加对应 volume 挂载。

### 2.2 构建并启动（推荐一键脚本）

```bash
cd ~/apps/xiaoshu-album
chmod +x scripts/pi/*.sh

./scripts/pi/deploy.sh     # 一键构建并启动
# 等价：sudo docker-compose up -d --build
```

其它一键命令：

| 脚本 | 作用 |
|------|------|
| `./scripts/pi/start.sh` | 启动（已有镜像） |
| `./scripts/pi/stop.sh` | 停止 |
| `./scripts/pi/restart.sh` | 重启 |
| `./scripts/pi/debug.sh` | 状态 + 日志 + 健康检查 + 磁盘/内存 |
| `./scripts/pi/xiaoshu-ctl.sh` | 全部子命令入口（含 logs / shell） |

### 2.3 验证

浏览器打开：

| 入口 | 地址 |
|------|------|
| 登录 | `https://<服务器IP>:8765/login`（自签证书需浏览器点继续） |
| 首页 | `https://<服务器IP>:8765/` |

首次访问会要求创建**超级用户**。

本机自检：

```bash
./scripts/pi/debug.sh
# 或
curl -k -sS -o /dev/null -w "%{http_code}\n" https://127.0.0.1:8765/login
# 期望输出 200
```

**重要：** 打开登录页后立刻创建超级用户。未创建前为开放模式（同网段可读写），详见 [安全说明.md](./安全说明.md)。

**注意：** `config.json` 必须是**文件**。若误变成空目录（Docker 挂载常见事故），删掉该目录后从 `config.example.json` 复制重建。

## 3. 日常启动 / 停止 / 重启

```bash
cd ~/apps/xiaoshu-album

./scripts/pi/start.sh      # 启动
./scripts/pi/stop.sh       # 停止
./scripts/pi/restart.sh    # 重启

# 或直接 docker-compose：
sudo docker-compose up -d
sudo docker-compose stop
sudo docker-compose restart
sudo docker-compose up -d --build   # 改代码后
```

容器配置了 `restart: unless-stopped`，机器重启后一般会自动拉起（Docker 服务需已开机自启）。

## 4. 查看 Docker / 服务状态

推荐：

```bash
./scripts/pi/debug.sh
./scripts/pi/xiaoshu-ctl.sh status
./scripts/pi/xiaoshu-ctl.sh logs 200
```

或：

```bash
cd ~/apps/xiaoshu-album

# 本项目容器是否在跑
sudo docker-compose ps

# 最近日志（实时跟踪加 -f）
sudo docker-compose logs --tail=100
sudo docker-compose logs -f

# 资源占用
sudo docker stats xiaoshu-album --no-stream

# Docker 引擎是否正常
sudo systemctl status docker
```

常见状态：

| `State` | 含义 |
|---------|------|
| `Up` | 正常运行 |
| `Exit` / `Exited` | 已退出，看 logs 排查 |
| `Restarting` | 反复崩溃，看日志 |

## 5. 重置超级用户密码

鉴权库在宿主机目录 `data/auth.sqlite`（已挂载进容器）。忘记密码时：

```bash
cd ~/apps/xiaoshu-album

# 交互式重置（会提示输入新密码；可选改用户名）
sudo docker-compose exec album python run.py --reset-admin-password
```

指定新用户名：

```bash
sudo docker-compose exec album python run.py --reset-admin-password --admin-user 新用户名
```

若容器未运行，可临时起一个一次性容器（仍挂载同一 `data/`）：

```bash
sudo docker-compose run --rm album python run.py --reset-admin-password
```

重置后用新密码打开：`http://<服务器IP>:8765/login`

## 6. 数据与目录说明

| 宿主机路径 | 用途 |
|------------|------|
| `album/` | 相册媒资（以后可迁到外接盘） |
| `inbox/` | 待入库 |
| `data/thumbs/` | 缩略图缓存（默认可在设置中改路径） |
| `data/` | 鉴权库、地图包、地点库等 |
| `config.json` | 运行配置（只读挂载进容器） |

**设置里可改路径：**「相册根目录」「缩略图缓存目录」。Docker 下若指向外接盘，需在 `docker-compose.yml` 增加对应 volume，路径填**容器内**挂载点。

备份建议至少包含：`album/`、`data/auth.sqlite`、`config.json`，以及需要的 `data/map_pack/`、`data/geo/`。

## 7. 常用排障

**打不开网页**

```bash
sudo docker-compose ps
sudo docker-compose logs --tail=50
ss -tlnp | grep 8765
```

**构建很慢 / 拉镜像失败**

- 检查 `/etc/docker/daemon.json` 镜像加速并 `sudo systemctl restart docker`
- 确认 `Dockerfile` 使用国内基础镜像与 pip 源（本仓库已默认配置）

**系统时间不对导致 apt 报错**

```bash
date
sudo timedatectl set-ntp true
# 必要时先手动对时再装包
```

**改了 `config.json` 不生效**

```bash
sudo docker-compose restart
```

### 开机自启与日常管理

容器已设 `restart: unless-stopped`，且系统 `docker` 服务默认开机启用，因此**树莓派重启后会自动拉起相册网站**，无需再手动部署。

常用命令：

```bash
cd ~/apps/xiaoshu-album

# 状态
sudo docker-compose ps
sudo docker ps --filter name=xiaoshu-album

# 查看日志
sudo docker-compose logs -f --tail=100

# 停止 / 启动 / 重启（不重建镜像）
sudo docker-compose stop
sudo docker-compose start
sudo docker-compose restart

# 更新代码后重建并启动
sudo docker-compose build
sudo docker-compose up -d

# 彻底删除容器（数据卷目录 album/inbox/data 仍保留在主机上）
sudo docker-compose down
```

### 网页管理 Docker？（可选）

**命令行已足够**查看状态，树莓派上一般不必再装面板：

```bash
sudo docker images
sudo docker ps -a
sudo docker stats --no-stream
sudo docker-compose ps
```

若确实想用网页：

| 方案 | 说明 | 资源 |
|------|------|------|
| **Portainer CE** | 常见轻量 Docker Web UI | 空闲约几十～百 MB 内存，对 Pi4 可接受，Pi3 偏紧 |
| 相册本站 | **不内置** Docker 管理页 | — |

建议：家庭相册场景用 `docker-compose` 命令即可；只有多容器/常改配置时再考虑 Portainer，且仅限局域网访问。

安全注意：首次启动后**立即创建超级用户**；勿将端口映射到公网。详见 [安全说明.md](./安全说明.md)。
