## v3.0.9（2026-10-25）

相对 **v3.0.8** 的增量，聚焦搜索完整性。

- **多词搜索**：空格（含全角空格）分词，每个词都要命中；例如「北京 西湖」不再要求两个词连在一起。
- **结果翻页**：默认每页更多结果，底部「加载更多」可翻到全部命中；分享选图搜索同样支持。
- **类型过滤**：顶栏「仅照片 / 仅视频」会真正进入查询，不再被另一类占满名额后在前端藏掉。
- **可搜感悟**：索引增加 `reflection` 字段；升级后如需搜到旧片感悟，请在设置里重建一次索引（只重写目录，不改照片）。

**公开仓库注意：** compose 与文档仅含示例路径（如 `/mnt/album-data`）；缩略图预热脚本路径改由环境变量 `ALBUM_WARM_THUMBS` 提供，仓库内不含本机磁盘路径。

## v3.0.8（2026-10-11）

相对 **v3.0.0** 的增量。

- **必须先注册**：还没有超级用户时，只能打开登录页完成创建。未建号不再等于开放读写。
- **内容指纹**：按画面或视频载荷计算（nometa），写入 SQLite。入库解析会标出「相册已有相同内容」。改过 EXIF 仍算同一份；重新压缩或改过尺寸不算同一份。
- **存储页**：占用和查重分成两组。相册原片体积来自索引。「重新统计」只重算回收站、待入库、缩略图、地图包等目录，不改照片、不清指纹。
- **媒资索引**：重建只重写目录库，不删除、不改写照片，并保留已有内容指纹。开始前有确认。
- **访问数据**：摘要先显示，其余统计随后补齐。
- **手机看图**：幻灯片用已缓存的清晰预览，画面在上下栏之间铺满并居中；视频同样铺满居中。页面不直接放入原图，避免手机解码失败。
- **Mac「从相册选择」**：网页不能指定打开系统「照片」图库。Safari 需在文件框侧栏点「照片」；Chrome 从「图片」文件夹开始。

**已知不足：** 图片旁白仍不稳定。Mac 无法默认进入「照片」图库。

指纹补算结束后，只有设置了环境变量 `ALBUM_WARM_THUMBS`（指向本机缩略图脚本）才会接着补缩略图。公开仓库不包含任何本机磁盘路径。

## v3.0.0（2026-10-05）

相对 **v2.1.0** 的增量。电脑端原有浏览 / 入库 / 地图能力保留；本版补了设置、分享与访问数据体验。

- **设置与分享**：设置页拆分加载，首屏不再被统计请求卡住；分享勾选支持搜索与结果全选；移动端分享缩略图不再互相重叠。
- **访问数据**：访客曲线与扇形更易读；列表过长可点开展开。
- **编辑窗**：保存按钮固定在栏底，电脑端不必再滚到最下面。
- **灯箱**：不会把旁白伴生文件当成图片打开。

**已知不足：** 图片旁白未做好（录音、幻灯片出声、与当前照片对齐不稳定），不列入本版可靠功能。

## v2.1.0（2026-10-05）

相对 **v2.0.0**（2026-10-04）的增量，电脑端功能保持不变。

- **手机浏览布局**：窄屏（约 720px 及以下）单独适配顶栏、时光 / 经典 / 地图、灯箱操作条、入库列表排版；电脑宽屏样式不改。

## v2.0.0（2026-10-04）发布基线

面向家庭局域网、树莓派常开主机：浏览、入库、地图、分享、存储去重、回收站。功能已够日常使用，作为 **V2.0 发布基线**。

### 相对 9 月 24 日初稿的补强

#### 入库与去重

- 内容指纹 **nometa-v1**：比对时尽量忽略 EXIF / 容器元数据，只认画面或视频有效载荷，改过拍摄信息的同一张图不会当成新文件。
- 无 EXIF 时间时，从**文件名**里的日期时间回填（常见相机/导出命名）。
- 待入库支持 **移除选中**、**清空待入库**（只删导入区，不进相册、不进回收站）。
- 确认框使用页面内 `<dialog>`，避免火狐在已有对话框时 `confirm()` 失效。
- 关闭入库预览后回到原先列表位置；经典模式缩略图观察器常驻，减少 Chrome 下缩略图被回收。
- 大批量上传自动限速，减轻树莓派网卡打满。
- 上传队列：暂停 / 继续 / 重试；历史上传目录可标记永久保留。

#### 浏览与视频

- 浏览器不能直接播的视频走服务端可播转码（`/api/play` 等），灯箱可看。
- 幻灯片预加载与入库进度条，减少「点了没反应」的感觉。
- Mac 资源叉（AppleDouble）等假视频不会当正常 MP4 播。

#### 地图与地点

- 中国大陆照片：高德模式下 WGS-84 → GCJ-02。
- **香港 / 澳门 / 台湾**按境外处理，不再二次纠偏（避免落到深圳等错误堆叠）。
- 地点库默认国内行政区；可用 `scripts/seed_world_places.py` 增补泰国等常用海外城市，出国照片才能按地名上图。
- 地图聚点粒度收紧，减少「整片地区合成一个点」。

#### 运维

- 相册与待入库可放到同一块外接盘（如 `/mnt/album-data`），入库用 rename，避免 SD 卡拷到 USB 把 IO 打满。
- 示例见仓库 `docker-compose.yml` / `docker-compose.pi.yml`。

## 升级后建议

1. 浏览器 **强制刷新**（静态资源 `?v=3.0.9`）。  
2. 若去重策略从「整文件 MD5」换成 nometa，可在存储页再扫一遍重复项（可能多发现一些「只改过 EXIF」的重复）。  
3. 有境外旅行照片：在服务器上对 `places.sqlite` 跑一次 `seed_world_places.py`，必要时重建/刷新地图索引。  

脚本：

```bash
# 国内行政区（重建库，需联网）
PYTHONPATH=.vendor python3 scripts/seed_places.py

# 在已有库上增补海外地点（不重建国内）
python3 scripts/seed_world_places.py
# Docker 内示例：
# sudo docker exec xiaoshu-album python3 /app/scripts/seed_world_places.py
```

容器镜像若未带 `scripts/`，可在挂载了 `data/geo` 的宿主机用 `PLACES_DB=` 指向库文件后执行。
